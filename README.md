## ♿ Real-Time Adaptive Accessibility Features

1. **Magic Clarity Lens:** A pointer-following magnifying glass that renders hovered text in crisp Google `Lexend` font.
2. **Real-Time Crayon Palette Switcher:**
   - 🖍️ *Wild Crayon Bleed* (Default kid notebook paper)
   - 🌙 *Midnight Chalkboard* (High-contrast dark mode)
   - ☀️ *Highlighter Yellow* (Ultra-high contrast WCAG 2.2 AAA with 18:1 ratio)
   - 📄 *Clean Slate* (Soft, low-sensory paper mode)
   - 🟢 *Cyber Phosphor* (Classic terminal green)
3. **"Nap Time" Reduced Motion Mode:** Silences line-boil filters, pauses bouncing springs, and stabilizes all animations.
4. **Procedural Web Audio API Synthesizer:** Zero external audio dependencies; synthesizes retro blips, crash thuds, and major-chord chimes in real time with instant mute.
5. **Text-To-Speech Narrator:** Native browser `speechSynthesis` reads the narrative aloud with active playback indicators.
6. **Font Scale Adjuster:** Instant typography scaling from 100% to 150%.
